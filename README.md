# 📝 Text Annotation App

Приложение для создания и аннотирования текстовых статей, построенное на Angular 18 с использованием реактивных подходов RxJS.

## 🚀 Возможности

- **Управление статьями**: создание, редактирование и удаление статей
- **Аннотирование текста**: выделение фрагментов текста с возможностью добавления примечаний
- **Цветовая маркировка**: выбор цвета для каждой аннотации
- **Всплывающие подсказки**: просмотр примечаний при наведении на аннотированный текст
- **Локальное хранение**: все данные сохраняются в localStorage браузера
- **Мобильная адаптивность**: интерфейс оптимизирован для работы на мобильных устройствах

## 📋 Требования

- npm 9+

### Покрытие тестами

Проект содержит **68 unit-тестов**, покрывающих все ключевые компоненты и сервисы.

#### 📌 Тип тестов

**Unit-тесты (модульные тесты)** — тесты, которые проверяют отдельные единицы кода (функции, методы, классы) в изоляции от других частей системы.

| Характеристика | Описание |
|----------------|----------|
| **Изоляция** | Каждый компонент/сервис тестируется отдельно с использованием моков |
| **Моки (mocks)** | Зависимости заменяются заглушками (`jasmine.createSpyObj`) |
| **Скорость** | Выполняются быстро, так как нет реальных HTTP-запросов и DOM |
| **Scope** | Проверяют логику отдельных методов и функций |

**Что НЕ используется в проекте:**

| Тип теста | Описание | Почему не используется |
|-----------|----------|------------------------|
| **E2E (End-to-End)** | Тестирует всё приложение в браузере как реальный пользователь | Требует Protractor/Cypress, сложнее поддерживать |
| **Интеграционные** | Проверяет взаимодействие нескольких компонентов вместе | Unit-тесты с моками достаточны для текущей архитектуры |

#### 📦 ArticleService (17 тестов)

**getAll()**
- Возвращает Observable с массивом статей
- Возвращает пустой массив при отсутствии данных

**create()**
- Создаёт новую статью и возвращает её
- Сохраняет статью в localStorage
- Генерирует уникальные ID для разных статей

**getById()**
- Возвращает статью по ID
- Возвращает undefined для несуществующего ID

**update()**
- Обновляет существующую статью
- Возвращает null для несуществующей статьи
- Сохраняет изменения в localStorage

**delete()**
- Удаляет существующую статью
- Возвращает false для несуществующей статьи
- Обновляет localStorage после удаления

**loadFromStorage()**
- Загружает статьи из localStorage при инициализации
- Корректно обрабатывает невалидный JSON (graceful degradation)

#### 🏷️ AnnotationService (17 тестов)

**getByArticleId()**
- Возвращает аннотации для конкретной статьи
- Возвращает пустой массив для статьи без аннотаций

**create()**
- Создаёт новую аннотацию и возвращает её
- Сохраняет аннотацию в localStorage
- Генерирует уникальные ID (с префиксом `ann-`)

**update()**
- Обновляет примечание аннотации
- Обновляет цвет аннотации
- Возвращает null для несуществующей аннотации
- Сохраняет изменения в localStorage

**delete()**
- Удаляет существующую аннотацию
- Возвращает false для несуществующей аннотации
- Обновляет localStorage после удаления

**deleteByArticleId()**
- Удаляет все аннотации для конкретной статьи
- Возвращает true даже при отсутствии аннотаций

**loadFromStorage()**
- Загружает аннотации из localStorage при инициализации
- Корректно обрабатывает невалидный JSON (graceful degradation)

### ⚠️ Примечание об ошибках в консоли

При запуске тестов вы можете увидеть сообщения об ошибках:

```
ERROR: 'Error parsing articles from localStorage', SyntaxError: Unexpected token 'i', "invalid json" is not valid JSON
```

**Это нормально!** Эти сообщения появляются из тестов `should handle invalid JSON in localStorage gracefully`, которые специально проверяют обработку повреждённых данных. Сервисы корректно восстанавливаются и возвращают пустой массив.

## 🌐 Деплой на GitHub Pages

Приложение настроено для развертывания на GitHub Pages с использованием `angular-cli-ghpages`.

### Автоматический деплой

```bash
ng deploy --base-href=/text-annotation-app/
```

Замените `text-annotation-app` на название вашего репозитория.

### Результат

После успешного деплоя приложение будет доступно по адресу:
```
https://<username>.github.io/text-annotation-app/
```

### Настройка репозитория

1. Откройте настройки репозитория на GitHub
2. Перейдите в **Settings** → **Pages**
3. Убедитесь, что Source установлен на `gh-pages` branch

### Примечание о маршрутизации

Приложение использует `HashLocationStrategy` для корректной работы маршрутизации на GitHub Pages. URL будут иметь вид:
```
https://<username>.github.io/text-annotation-app/#/articles/123
```

## 🎯 Функциональность

### Работа со статьями

| Действие | Описание |
|----------|----------|
| Создать статью | Кнопка "Создать статью" на главной странице |
| Редактировать статью | Кнопка ✏️ на карточке статьи |
| Удалить статью | Кнопка 🗑️ на карточке статьи |
| Просмотреть статью | Клик по карточке статьи |

### Работа с аннотациями

1. **Создание аннотации**:
   - Откройте статью в режиме просмотра
   - Выделите фрагмент текста
   - В появившемся модальном окне выберите цвет и добавьте примечание
   - Нажмите "Создать аннотацию"

2. **Просмотр аннотации**:
   - Наведите курсор на подсвеченный текст
   - Примечание отобразится во всплывающей подсказке

3. **Редактирование/Удаление аннотации**:
   - Кликните по аннотированному тексту
   - Введите `edit` для редактирования или `delete` для удаления

### Технологии

| Технология | Версия | Назначение |
|------------|--------|------------|
| Angular | 18.2.0 | Frontend фреймворк |
| TypeScript | 5.5.2 | Язык программирования |

| SCSS | - | Стилизация |

### Архитектурные решения

- **Standalone Components**: использование автономных компонентов без NgModules
- **Reactive State Management**: управление состоянием через BehaviorSubject
- **Dependency Injection**: сервисы предоставляются через `providedIn: 'root'`
- **HashLocationStrategy**: для работы маршрутизации на статических хостингах
- **Range API**: для работы с выделением текста и позиционированием аннотаций
- **localStorage API**: для персистентного хранения данных

| `/articles/:id` | ArticleEditorComponent | Просмотр статьи |
| `/articles/:id/edit` | ArticleEditorComponent | Редактирование статьи |

  id: string;

## 🔒 Хранение данных

Данные сохраняются в localStorage браузера:

- `text_annotation_articles` — массив статей
- `text_annotation_annotations` — массив аннотаций
