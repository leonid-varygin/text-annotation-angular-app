# 🛠️ Установка и запуск

## 📋 Требования

- Node.js 18+
- npm 9+
- Angular CLI 18+

## 🚀 Установка

```bash
git clone <repository-url>
cd text-annotation-app
npm install
```

## 🏃 Запуск

```bash
npm start
```

Приложение будет доступно по адресу `http://localhost:4200/`

## 🏗️ Сборка

```bash
npm run build
```

Артефакты сборки будут размещены в директории `dist/`
